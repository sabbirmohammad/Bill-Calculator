## ✨ প্রধান বৈশিষ্ট্যসমূহ (Key Features)

### 🧮 ১. নির্ভুল ট্যারিফ ক্যালকুলেশন ইঞ্জিন
- **বাংলাদেশ এনার্জি রেগুলেটরি কমিশন (BERC)** এর ৬টি আবাসিক স্ল্যাব ও লাইফলাইন রেট অনুযায়ী ১০০% নির্ভুল বিল হিসাব।
- ডিমান্ড চার্জ, মিটার রেন্ট, ভ্যাট (VAT ৫%) এবং লেট ফি পৃথকভাবে আইটেমাইজড রসিদ আকারে প্রদর্শন।
- **What-If সিমুলেটর:** নির্দিষ্ট ইউনিট ব্যবহার কমালে বা বাড়ালে বিলে কী পরিমাণ সাশ্রয় হবে তা রিয়েল-টাইমে পর্যবেক্ষণ।

### 📊 ২. অ্যানালিটিক্স ও ড্যাশবোর্ড
- কারেন্ট বিলিং সাইকেল প্রগ্রেস, আনুমানিক মাস শেষের বিল ও পূর্বাভাস (Forecast)।
- কাস্টম জেটপ্যাক কম্পোজ চার্টস (Bar chart, Trend line chart, Weekday usage heatmap, Slab breakdown donut chart)।
- অ্যানোমালি ও হাই-ইউসেজ ডিটেকশন অ্যালগরিদম।

### 🔒 ৩. শীর্ষস্তরের নিরাপত্তা ও গোপনীয়তা (Hardware-Backed Security)
- **SQLCipher 256-bit AES ডাটাবেস এনক্রিপশন:** মাস্টার কী সরাসরি হার্ডওয়্যার-ব্যাকড `AndroidKeyStore` এ সংরক্ষিত।
- **বায়োমেট্রিক অ্যাপ লক:** ফিঙ্গারপ্রিন্ট বা ডিভাইস ক্রেডেনশিয়াল সাপোর্ট।
- **প্রাইভেসি মোড:** এক ট্যাপে অ্যামাউন্ট মাস্কিং (`৳ ••••`) এবং মাল্টিটাস্কিং/স্ক্রিনশট ব্লকিং প্রোটেকশন (`FLAG_SECURE`)।
- **এনক্রিপ্টেড ব্যাকআপ:** ব্যাকআপ ও রিস্টোর সম্পূর্ণ অফলাইনে ডিভাইসের মধ্যে সুরক্ষিত।

### 🌐 ৪. বাংলা ও ইংরেজি পূর্ণাঙ্গ লোকালাইজেশন
- সম্পূর্ণ বাংলা ও ইংরেজি ইন্টারফেস এক ট্যাপে পরিবর্তনযোগ্য।
- বাংলা ডিজিটস সাপোর্ট (যেমন: ১২৩৪৫.৬ kWh, ৳২,৫০০.০০)।

### 🔄 ৫. সম্পূর্ণ মসৃণ গিটহাব অটো-আপডেট (Seamless OTA)
- অ্যাপের ভেতর থেকেই স্বয়ংক্রিয়ভাবে নতুন রিলিজ ডিটেকশন ও রিয়েল-টাইম স্পিড ইন্ডিকেটর সহ ডাউনলোড।
- কোনো কনফিগারেশন বা টেকনিক্যাল ঝামেলা ছাড়াই সরাসরি আপডেট সম্পন্ন।

## 🛠️ বিল্ড ও ডেভেলপমেন্ট (Build from Source)

```bash
# রিপোজিটরি ক্লোন করুন
git clone https://github.com/sabbirmohammad/Bill-Calculator.git
cd Bill-Calculator

# ইউনিট টেস্ট রান করুন
./gradlew testDebugUnitTest

# কোড কোয়ালিটি ও লিন্ট চেক
./gradlew detekt ktlintCheck

# কানেক্টেড অ্যান্ড্রয়েড টেস্ট (এমুলেটর বা ডিভাইসে)
./gradlew connectedDebugAndroidTest

# রিলিজ APK বিল্ড
./gradlew assembleRelease
```
বিল্ড সম্পন্ন হওয়ার পর APK পাওয়া যাবে:  
`app/build/outputs/apk/release/app-release.apk`
