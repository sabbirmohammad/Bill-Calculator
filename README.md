# ⚡ বাংলাদেশ বিদ্যুৎ বিল ক্যালকুলেটর (Bangladesh Electricity Bill Calculator)

একটি আধুনিক, দৃষ্টিনন্দন এবং নির্ভুল ওয়েব অ্যাপ্লিকেশন — যা বাংলাদেশ এনার্জি রেগুলেটরি কমিশন (BERC) কর্তৃক নির্ধারিত আবাসিক (LT-A) গ্রাহকদের জন্য ৬টি ধাপে স্ল্যাবভিত্তিক বিদ্যুৎ বিল হিসাব করার জন্য তৈরি করা হয়েছে।

---

## 📋 বিলের ট্যারিফ ও স্ল্যাব রেট (BERC Residential LT-A)

| ধাপ / স্ল্যাব | ইউনিটের পরিসীমা | রেট (প্রতি ইউনিট) | বিবরণ |
|---|---|---|---|
| **লাইফলাইন (Lifeline)** | **০ – ৫০ ইউনিট** | **৳৪.৬৩** | স্বল্প আয়ের গ্রাহকদের জন্য বিশেষ ভর্তুকিযুক্ত রেট |
| **ধাপ ১ (Step 1)** | **০ – ৭৫ ইউনিট** | **৳৫.২৬** | প্রাথমিক আবাসিক ব্যবহারের ধাপ |
| **ধাপ ২ (Step 2)** | **৭৬ – ২০০ ইউনিট** | **৳৭.২০** | পরবর্তী ১২৫ ইউনিটের হিসাব |
| **ধাপ ৩ (Step 3)** | **২০১ – ৩০০ ইউনিট** | **৳৭.৫৯** | পরবর্তী ১০০ ইউনিটের হিসাব |
| **ধাপ ৪ (Step 4)** | **৩০১ – ৪০০ ইউনিট** | **৳৮.০২** | পরবর্তী ১০০ ইউনিটের হিসাব |
| **ধাপ ৫ (Step 5)** | **৪০১ – ৬০০ ইউনিট** | **৳১২.৬৭** | পরবর্তী ২০০ ইউনিটের হিসাব |
| **ধাপ ৬ (Step 6)** | **৬০০ ইউনিটের উপরে** | **৳১৪.৬১** | ৬০০ ইউনিটের বেশি অবশিষ্ট ইউনিটের হিসাব |

> **নোট**: কোনো গ্রাহক এক মাসে ৫০ বা তার কম ইউনিট ব্যবহার করলে স্বয়ংক্রিয়ভাবে লাইফলাইন রেট (৳৪.৬৩) প্রযোজ্য হবে। ব্যবহার ৫০ ইউনিটের বেশি হলেই তা স্বাভাবিক ধাপভিত্তিক (০-৭৫ ইউনিট @ ৳৫.২৬ ইত্যাদি) হিসাবে চলে যাবে।

## ✨ অ্যাপ্লিকেশনের মূল বৈশিষ্ট্যসমূহ (Features)

1. **রিয়েল-টাইম ক্যালকুলেটর (Live Interactive Calculator):**
   - ইউনিট ইনপুট বা স্লাইডার দিয়ে সহজেই মোট ইউনিট নির্ধারণ করা যায়।
   - তাৎক্ষণিক মোট বিদ্যুৎ শক্তি চার্জ (Energy Charge), ডিমান্ড চার্জ, মিটার ভাড়া ও ৫% সরকারি ভ্যাটসহ পূর্ণাঙ্গ বিল প্রকাশ।

2. **ধাপভিত্তিক পুঙ্খানুপুঙ্খ বিবরণ (Step-by-Step Slab Breakdown):**
   - কোন ধাপে কত ইউনিট বরাদ্দ হলো এবং সেই ধাপের মোট খরচ কত তা রঙিন প্রোগ্রেস বারসহ স্পষ্ট প্রদর্শন।

3. **হোম অ্যাপ্লায়েন্স হিসাবক (Household Appliance Estimator):**
   - ফ্যান, এসি, ফ্রিজ, টিভি, লাইট, মোটর পাম্প ইত্যাদি কোন যন্ত্র কয়টি এবং দিনে কত ঘণ্টা চললে কত ইউনিট ও কত টাকা খরচ হবে তা পরিমাপ করার সুবিধা।

4. **বাজেট থেকে ইউনিট রিভার্স ক্যালকুলেটর (Budget to Units Estimator):**
   - আপনার মাসিক বাজেট (যেমন: ৳২,০০০ বা ৳৫,০০০) লিখলে আপনি কত ইউনিট খরচ করতে পারবেন এবং দৈনিক কত ইউনিট ব্যবহার নিরাপদ তা নির্ভুলভাবে হিসাব করে দেয়।

5. **বিল রিসিট প্রিন্ট ও ডাউনলোড (Printable Official Statement):**
   - ডেস্কো (DESCO) বা ডিপিডিসি (DPDC)-এর আদলে একটি পেশাদার বিল বিবরণী রিসিট এক ক্লিকেই প্রিন্ট বা PDF হিসেবে সংরক্ষণ করা যায়।

6. **উন্নত ইউআই / ইউএক্স এবং অ্যানিমেশন (Modern UI/UX & Animations):**
   - ডার্ক ও লাইট মোড (Dark & Light Theme) টগল।
   - দ্বৈত ভাষা সমর্থন (বাংলা এবং ইংরেজি)।
   - গ্লাস মরফিজম, ইলেকট্রিক গ্লো এফেক্ট, কনফেটি সেলিব্রেশন ও আধুনিক টাইপোগ্রাফি।

### 🔄 ইন-অ্যাপ অটোমেটিক আপডেট (In-App Auto-Update)
* **স্বয়ংক্রিয় নোটিফিকেশন:** ফোনে অ্যাপটি ইনস্টল করা থাকলে, গিটহাবে নতুন কোনো রিলিজ আসার সাথে সাথে অ্যাপ ওপেন করলেই মডার্ন আপডেট ডায়ালগে পরিবর্তনের বিবরণী (Changelog) প্রদর্শিত হবে।
* **এক ক্লিকে ডাউনলোড ও ইনস্টল:** কোনো ব্রাউজারে না গিয়ে সরাসরি অ্যাপের ভেতরেই লাইভ প্রগ্রেস বার সহ নতুন APK ডাউনলোড ও ইনস্টল হয়ে যাবে।
* **ম্যানুয়াল চেক:** সেটিংস পেজ থেকে যেকোনো সময় **"নতুন আপডেট চেক করুন"** অপশনে ট্যাপ করে আপডেট যাচাই করা যাবে।

### 🚀 গিটহাবে নতুন ভার্সন আপলোড করার নিয়ম
যখনই আপনি অ্যাপের কোনো কোড পরিবর্তন বা আপডেট করবেন:
1. `android/app/build.gradle.kts` ফাইলে `versionCode` (যেমন: 2) এবং `versionName` (যেমন: `"1.0.1"`) বৃদ্ধি করুন।
2. গিটহাবে কমিট করে একটি নতুন ট্যাগ পুশ করুন:
   ```bash
   git add .
   git commit -m "feat: নতুন সংস্করণ v1.0.1 রিলিজ"
   git tag v1.0.1
   git push origin main --tags
   ```
3. GitHub Actions CI/CD স্বয়ংক্রিয়ভাবে রিলিজ APK বিল্ড করবে এবং GitHub Releases-এ অ্যাটাচ করে দেবে। ফলে সমস্ত ইনস্টল করা ফোনে সাথে সাথে আপডেটের নোটিফিকেশন চলে যাবে!

## 🚀 ওয়েব সংস্করণ কীভাবে চালাবেন (Web App)

### ১. ডিপেন্ডেন্সি ইনস্টল করুন:
```bash
npm install
```

### ২. ডেভেলপমেন্ট সার্ভার চালু করুন:
```bash
npm run dev
```
এরপর ব্রাউজারে `http://localhost:5173` ওপেন করুন।

### ৩. প্রডাকশন বিল্ড তৈরি ও প্রিভিউ:
```bash
npm run build

```
